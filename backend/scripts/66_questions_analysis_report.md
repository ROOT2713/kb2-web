**优先级**: P1

## 四、expected 格式改进建议

### 4.1 当前问题诊断

| 问题 | 影响范围 | 严重度 |
|------|---------|:------:|
| `must include: [数据缺口] 知识库未收录` 字符串不匹配任何 KB 回答 | R01-R25 (25题) | 🔴 100% false fail |
| 单值 keyword 过于严格（如 `24±1℃`、`0.5-0.7s`） | F01, F12 | 🔴 实际正确但判 fail |
| 多 keyword "所有全命中" 阈值高（hits ≥ len/2 还漏检） | O/C 系列 | 🟡 partial pass 被判 fail |
| 措辞变体未覆盖（"每年至少一次" vs "每年至少进行一次"） | F13 | 🟡 false negative |
| 标准号格式不统一（"GB50174" vs "GB 50174-2017"） | C02 | 🟡 依赖 fallback 逻辑 |

### 4.2 改进方案

**方案 A: 分级 expected (推荐)**

```
# 目前
"expected": "must include: 24±1℃"

# 改为分级 (Level 1 = 必须, Level 2 = 建议)
"expected": {
  "strict": ["24±1℃"],           // 必须精确匹配
  "fuzzy": ["温度", "24℃"],       // 模糊匹配
  "reject_format": "semantic"     // 拒答用语义判断
}
```

**方案 B: 为 R 系列设计独立判断模式**

```
# 目前 failed: 所有 25 题都找一个不存在的字符串
"expected": "must include: [数据缺口] 知识库未收录"

# 改为
"expected": "[reject] from all banks"
# 或更精确:
"expected": "[reject] query requires external knowledge outside KB scope"
```

**方案 C: keyword 匹配增强**

1. 标准化号匹配: 自动去掉空格/斜杠，如 `GB50174` == `GB 50174-2017`
2. 数值区间匹配: 支持 `18℃~27℃` contains `24` 或 `24±1` 的语义匹配
3. 同义词扩展: "门禁" ≈ "出入口控制", "消防" ≈ "火灾报警"

**类型 1: 文档路径/层次测试 (Depth) — 新增 5-8 题**

| 示例 | 测试目标 |
|------|---------|

| "东莞造价指南中软件开发费的功能点测算法单价表格" | 表格检索 |
| "等保三级安全计算环境中的身份鉴别包含哪几个控制点" | 标准层级穿透 |

**类型 2: 否定/排除测试 (Negation) — 新增 3-5 题**

| 示例 | 测试目标 |
|------|---------|
| "数据中心机房温度不需要达到什么值" | 否定句式理解 |
| "等保测评周期中，哪级系统不需要每年测评" | 排除逻辑 |

**类型 3: 数值/表格型精确测试 (Precision) — 新增 5 题**

| 示例 | 测试目标 |
|------|---------|

| "GB 50052 第 5.0.15 条规定的三相供电电流阈值" | 条款精确值 |

**类型 4: 更新/修正型测试 (Recency) — 新增 3 题**

| 示例 | 测试目标 |

| "等保2.0相比1.0测评周期变化" | 版本差异 |

## 七、总结

**测试集整体质量**: 良 — 架构合理、覆盖库内主要话题，但存在 3 类系统性问题

**核心发现**:
